# Testplex tester feedback trackers

Use the public [bug report form](https://github.com/joshbet9/testplex/issues/new?template=bug_report.yml) or [game idea form](https://github.com/joshbet9/testplex/issues/new?template=game_idea.yml). Select the relevant game. The report is automatically tagged, assigned for triage, and attached as a native GitHub sub-issue under its tracker below.

Submit one independently actionable report per issue. Monster Maze Original, Speed, and Modern share one tracker and retain the selected mode on each report. Use the shared tracker for lobby or cross-game behavior.
