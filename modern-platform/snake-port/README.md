# Snake — modern Paper 26.3 mechanics port

This is a standalone, Paper-native first-pass port of the Arcade Snake mechanics for the modern Testplex test platform. It runs separately from the legacy Java 8 server and makes its own `snake_arena` test world if needed.

## Current mechanics
- Sheep-headed player snakes with a following sheep tail; length grows over time and from green slime food.
- Speed, Reverse and Invulnerable kits with short timed abilities.
- Physical, steering magma-cube item-box hazards (10-second first spawn, then 15-second intervals, four-cube cap, source-style 0.12 steering every four ticks and preserved hop/gravity); touching a box during an active roulette no longer consumes it, with an animated hotbar roll.
- Four per-player steering effects (Turn Lag, Drift, Overshoot and Weak Sharp Turning) whose durations escalate on repeat hits: 1, 3, 5, 10, 15, 20, then 30 seconds.
- Tail/self-tail collision, idle/wall/quit elimination, spectator transitions and player inventory/location restoration.
- Solo mode for long-running mechanics tests; multiplayer starts when multiple players queue.

## Commands
- `/gamepanel` → Snake → Start / Test Snake.
- `/snake join`, `/snake start`, `/snake kit <speed|reverse|invulnerable>`, `/snake status`, `/snake leave`.
- `/snake stop` is operator-only.

## Status and limitations
This is a mechanics-first compatibility port, not a final parity sign-off. It intentionally does not implement Snake cosmetics or its dedicated victory scene yet. Verify mounted controls, collision distances, tail spacing, item-box contacts and cleanup in a running Paper 26.3 server before marking it ready. The new cosmetic line and unique win effect come after Monster Maze and Snake mechanics have been accepted.

The arena is generated by the plugin as a bounded test surface; original Arcade map ZIPs are not required for this first pass.
